# KOX Performance Edition

**Official public download page for KOX Performance Edition.**

This repository is used only to distribute public Android APK releases.
The application source code and development repository are maintained separately and are not published here.

## Download

Open the **Releases** page to download the latest APK:

https://github.com/KOXAIN48/KOX-Performance/releases

If no release is listed yet, the next public APK release is still being prepared.

## Installation

1. Download the APK from the Releases page.
2. Open the downloaded APK on your Android device.
3. Allow installation from this source if Android asks.
4. Install and launch the application.

## Notes

- Only APK distribution files and release notes belong in this repository.
- Check the release notes for build information and known limitations.
- Install APKs only from this official repository.
